# Banjarnegara Vector Map

Generated from OpenStreetMap data supplied by the Geofabrik Java extract using Planetiler.

- `banjarnegara.pmtiles`: 32.56 MB, PMTiles v3, MVT tiles, gzip compressed
- `banjarnegara.mbtiles`: 36.99 MB, source archive
- Bounds: `109.2,-7.45,109.9,-7.18`
- Native zoom: 0-16; suitable for overzoom display through 19
- Attribution: OpenMapTiles and OpenStreetMap contributors

The PMTiles file must be hosted at a public URL before the mobile app can download it after installation. It is intentionally not bundled into the APK.
